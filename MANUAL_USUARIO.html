1. Introducción

El sistema Cruce ARBA-AGIP es una aplicación web diseñada para conciliar retenciones entre los registros de ARBA y AGIP. Permite cargar archivos Excel con datos de ambas fuentes y realizar cruces automáticos o manuales para identificar coincidencias.

1.1 Requisitos del Sistema

  • Navegador web moderno (Chrome, Firefox, Edge)
  • Conexión a internet (solo para acceso remoto)
  • Archivo Excel con formato específico (ver sección 3)

1.2 Acceso al Sistema

Abra su navegador web e ingrese la dirección proporcionada por el administrador:

URL local: http://localhost
URL remota: Consultar con el administrador del sistema

3. Carga de Archivos Excel

3.1 Formato del Archivo

El archivo Excel debe contener las siguientes hojas:

Hoja Columnas Requeridas
RETENCION (o RETIENCION) CUIT, Importe, PERIODO TOMADO
PLATAFORMA CUIT, Importe, PERIODO
Importante: El sistema detecta automáticamente si la hoja se llama "RETENCION" o "RETIENCION" (con error tipográfico).

3.2 Pasos para Cargar

1
Preparar el archivo
Asegúrese de que el archivo Excel tenga el formato correcto con las hojas y columnas requeridas.
2
Arrastrar o seleccionar
Arrastre el archivo Excel sobre la zona de carga O haga clic en la zona para abrir el selector de archivos.
3
Confirmar carga
El sistema procesará el archivo y mostrará la cantidad de registros cargados de cada hoja.
Después de cargar, las tarjetas de estadísticas se actualizarán automáticamente mostrando la cantidad de registros pendientes.

4. Auto-Match (Cruce Automático)

El sistema puede detectar automáticamente coincidencias entre registros de RETENCION y PLATAFORMA basándose en:

  • CUIT: Debe ser idéntico
  • Monto: Debe coincidir con tolerancia de $0.01

4.1 Ejecutar Auto-Match

1
Haga clic en el botón "Auto-Match" (color azul).
2
El sistema buscará coincidencias y mostrará una tabla con los resultados encontrados.
3
Revise los resultados:
  • Cada fila muestra un match potencial
  • El indicador "OK" confirma que los montos coinciden
  • El indicador "DIF" advierte diferencia (dentro de tolerancia)

4.2 Seleccionar Matches

Antes de confirmar, puede:

  • Seleccionar individualmente: Use los checkboxes en cada fila
  • "Todos": Selecciona todos los matches
  • "Ninguno": Deselecciona todos

4.3 Confirmar o Descartar

  • ✓ (verde): Confirma los matches seleccionados y los guarda en la base de datos
  • 🗑 (rojo): Descarta todos los matches sin guardar

5. Cruce Manual

Para registros que no coinciden automáticamente, puede realizar cruces manuales.

5.1 Seleccionar Registros

1
En la tabla RETIENCION, haga clic en el checkbox de la fila que desea cruzar.
2
En la tabla PLATAFORMA, haga clic en el checkbox de la fila correspondiente.
3
Aparecerá un panel superior mostrando:
  • Monto total seleccionado en RET
  • Monto total seleccionado en PLAT
  • Diferencia entre ambos
Puede seleccionar múltiples registros de cada lado. El sistema generará todas las combinaciones posibles (producto cartesiano).

5.2 Generar Staging

1
Haga clic en "Cruce Manual (NxM)" donde N y M son las cantidades seleccionadas.
2
Aparecerá una tabla de Staging con todas las combinaciones generadas.
3
Revise las combinaciones y haga clic en "Confirmar" para guardar.

6. Otras Funciones

6.1 Actualizar Datos

El botón "Actualizar" recarga los datos de la base de datos sin necesidad de subir el archivo nuevamente.

6.2 Limpiar Base de Datos

El botón "Limpiar BD" elimina todos los datos de la base de datos:

¡Cuidado! Esta acción es irreversible. Eliminará:
  • Todos los registros pendientes
  • Todo el histórico de cruces

8. Solución de Problemas

Problema Solución
El archivo no carga Verificar que sea formato .xlsx o .xls y tenga las hojas correctas
No hay matches automáticos Verificar que los CUIT y montos coincidan exactamente
La página no responde Recargar la página (F5) o reiniciar el contenedor Docker
Datos perdidos Los datos persisten en MongoDB. Usar "Actualizar" para recargar
